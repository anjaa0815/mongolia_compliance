# Mongolia Banking модуль (Монгол банк, төлбөрийн нутагшуулалт)

`mongolia_compliance` аппын "Mongolia Banking" модуль. ERPNext-ийн цөм кодыг өөрчлөхгүй.

1. **QPay v2 төлбөрийн гарц**: борлуулалтын нэхэмжлэх / захиалгаас QR нэхэмжлэх үүсгэж, төлөгдмөгц Payment Entry автоматаар үүснэ.
2. **Банкны хуулга импорт ба автомат тулгалт**: Хаан, Голомт, ХХБ, Хас банкны Excel/CSV хуулгыг Bank Transaction болгон оруулж, төлбөрийн бичилттэй тулгана.
3. **Төгрөгийн формат**: MNT, ₮, `YYYY-MM-DD`, мянгатын тусгаарлагч, дүнг бүхэл төгрөгөөр харуулах сонголт.

`bench --site <site> install-app mongolia_compliance` хийхэд "QPay" төлбөрийн хэлбэр, Монголын банкууд (Bank), банк бүрийн хуулгын загвар, Mongolia Banking Settings үүсч, MNT/₮/YYYY-MM-DD формат хэрэглэгдэнэ (`setup.py`). `bench migrate` бүрт дутуу бичлэгүүдийг нөхнө, хэрэглэгчийн засварыг дарж бичихгүй.

## 1. QPay

**QPay Settings** (компани бүрт нэг):

| Талбар | Утга |
|---|---|
| Client ID / Client secret | QPay-ээс олгосон merchant нэвтрэх нэр, нууц үг |
| Нэхэмжлэхийн код | `invoice_code` (жишээ нь `TEST_INVOICE`) |
| Туршилтын орчин | `merchant-sandbox.qpay.mn` руу холбогдоно |
| Орлого хүлээн авах данс | Төлбөр энэ дансанд орно. QPay шимтгэлээ хасаад өдрийн эцэст банкны дансанд шилжүүлдэг тул "QPay клиринг" гэх мэт тусдаа данс зөвлөнө |
| Сайтын нийтэд нээлттэй хаяг | QPay-ийн callback ирэх `https://` хаяг |

"Холболт шалгах" товч токен авч үзнэ.

**Ашиглах**: батлагдсан Sales Invoice (эсвэл Sales Order) → **Create → QPay-ээр төлүүлэх**. QR код, банкны апп-ын холбоосууд гарч ирнэ. Харилцагч төлмөгц:

1. QPay `.../api/method/mongolia_compliance.mongolia_banking.payments.qpay_callback?token=…` хаягийг дуудна. Callback-д гарын үсэг байдаггүй тул апп төлбөрийг `/v2/payment/check`-ээр дахин баталгаажуулна.
2. Нэхэмжлэхийн эсрэг Payment Entry үүсч батлагдана (reference no = QPay payment id).
3. Callback ирэхгүй (сайт интернэтээс харагдахгүй) үед 5 минут тутам ажилладаг scheduler шалгана.

Бүх QR нэхэмжлэх **Mongolia Gateway Invoice** жагсаалтад хадгалагдана. Нэхэмжлэхийг цуцлахад төлөгдөөгүй QR нь QPay дээр цуцлагдана.

**Бусад гарц (SocialPay, Хаан банк, Голомт банкны corporate gateway)**: `mongolia_banking/gateways/base.py`-ийн `PaymentGatewayClient`-ийг хэрэгжүүлж (create_invoice, check_payments, cancel_invoice), өөр аппын `hooks.py`-д бүртгэнэ:

```python
mongolia_payment_gateways = {"SocialPay": "my_app.socialpay.get_client"}
```

Нэхэмжлэх, callback, Payment Entry үүсгэх урсгал нь бүх гарцад нэг.

## 2. Банкны хуулга

**Mongolia Bank Statement Upload** → байгууллагын банкны данс, интернэт банкнаас татсан файл (XLSX, XLS, CSV) → **Урьдчилан харах** → **Импортлох**.

- Хуулгын дээд талын гарчиг (компанийн нэр, данс, хугацаа) болон доод талын "Нийт" мөрийг алгасаж, толгой мөрийг автоматаар олно.
- Огноо, Гүйлгээний утга, Орлого/Зарлага (эсвэл +/- Дүн, Дт/Кт төрөл), Харьцсан данс, Гүйлгээний дугаар, Үлдэгдэл баганыг уншина.
- Нэг хуулгыг дахин оруулахад давхардсан мөрийг алгасна.
- Харьцсан данс нь харилцагчийн Bank Account-тай таарвал гүйлгээнд харилцагчийг онооно.

**Автомат тулгалт** нь гүйлгээ бүрийг оноогоор харьцуулна:

| Шинж | Оноо |
|---|---|
| Дүн тэнцүү | 50 |
| Гүйлгээний утгад баримтын дугаар (нэхэмжлэх, Payment Entry) | 40 |
| Гүйлгээний дугаар = Payment Entry-ийн reference no | 40 |
| Харьцсан данс = харилцагчийн данс | 30 |
| Утгад харилцагчийн нэр | 15 |
| Огноо ±1 хоног | 10 |

70-аас дээш оноотой, хоёрдугаар хувилбараасаа 15-аас илүү зөрүүтэй ганц таарц байвал л тулгана. Зөвхөн дүн таарсан гүйлгээг тулгахгүй, Bank Reconciliation Tool дээр гараар шийдвэрлэнэ.

Тулгах Payment Entry байхгүй ч гүйлгээний утгад төлөгдөөгүй нэхэмжлэхийн дугаар (эсвэл харилцагчийн данс) байвал Payment Entry үүсгээд тулгана ("Нэхэмжлэхийн дугаар таарвал төлбөрийн бичилт үүсгэх" сонголт).

Банк экспортын форматаа өөрчилбөл **Mongolia Bank Statement Format** дээр баганын нэрийг засна (нэг мөрөнд нэг нэр).

## 3. Формат (Mongolia Banking Settings)

| Сонголт | Үр дүн |
|---|---|
| Үндсэн валютыг төгрөг болгох | Global Defaults → MNT |
| ₮ тэмдгийг дүнгийн ард | `1,500,000.00 ₮` |
| Мянгатын тусгаарлагч | `#,###.##` эсвэл `#.###,##` |
| Огноог YYYY-MM-DD | System Settings → `yyyy-mm-dd` |
| **Төгрөгийн дүнг бүхэл тоогоор** | MNT-ийн формат `#,###`, "Rounded Total" бүхэл төгрөгөөр. USD, CNY зэрэг бусад валют 2 оронтой хэвээр |

Бүхэл тооны сонголтыг асаахад System Settings-ийн "Currency Precision" хоосорч, "Use Number Format from Currency" асна (валют бүр өөрийн форматаар нарийвчлалаа авдаг Frappe-ийн механизм). Анхаар: MNT-ийн бүх мөнгөн дүн, түүний дотор нэгж үнэ бүхэл төгрөгөөр хадгалагдана.

## Тест

```bash
python -m pytest mongolia_compliance/mongolia_banking/tests  # репогийн үндсэн хавтаснаас
```

Хуулга задлагч, тулгалтын оноо, QPay клиентийг (хуурамч HTTP session-оор) шалгана. Bench дээр, бодит QPay-тэй хараахан ажиллуулаагүй.

## Шалгах шаардлагатай

- Банк бүрийн экспортын баганын нэрийг бодит хуулгаар нягтлах (`statement/profiles.py`).
- QPay-ийн production орчинд callback, `payment/check`-ийн хариуг турших.
